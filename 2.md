# New Feature: Dynamic User Configuration
Instead of hardcoding the Google Drive Folder ID and Google Sheet ID in environment variables, the app must allow the user to link their own destinations dynamically in the UI.

1. **Settings UI:** Build a "Configuration" screen/modal where the user pastes their `Google Sheet ID` (or full URL) and `Google Drive Folder ID` (or full URL). The frontend should parse the actual IDs from the URLs if necessary.
2. **Local Storage:** Save these IDs in the browser's `localStorage` and pass them as payload parameters to the Next.js API routes on every request.
3. **Dynamic API Execution:** The backend APIs must use the provided `spreadsheetId` for database appends and the `driveFolderId` (in the `parents: []` array) for image uploads.

# Backend Auto-Initialization (The "Blank Sheet" Handler)
If a user links a completely blank Google Sheet, the backend must detect this and configure it automatically.

1. **Header Check:** In the `/api/save-lead` route, before appending the new lead, use `sheets.spreadsheets.values.get` to read the range `Sheet1!A1:J1`.
2. **Auto-Write Headers:** If the response is empty (i.e., the sheet is blank), perform a write operation to set the Row 1 headers exactly as:
   `Role | Name | Mobile | Email | Age | Gender | Address | Company | Photo_Drive_Link | Timestamp`
3. **Data Append:** Once headers are verified or created, append the actual visitor data to the next available row.

# Business Logic: The 3-Path Workflow
The app opens to a Role selector (`User` / `Company`). When `User` is selected, the workflow proceeds as follows:

### Path 1: Card with Information + Photo
1. **Capture:** Snap a photo of the visitor's card.
2. **Processing:** The frontend calls the Next.js API. The API concurrently runs `Promise.all` to:
   - Query the Gemini API with a strict JSON schema prompt to extract data AND return `face_detected: true`.
   - Upload the full card image to the dynamically provided Google Drive Folder, returning the `webViewLink`.
3. **Preview:** The frontend uses a typewriter effect to auto-fill the form (Name, Age, Mobile, Email, Address, Gender, Company). The input fields must remain editable controlled components so typos can be corrected instantly.
4. **Save:** Clicking "Save" calls the backend to auto-initialize headers (if blank) and append the form data + generated Drive link to the user's Google Sheet.

### Path 2: No Card (Manual Entry + Live Photo) - *Zero AI Usage*
1. **Capture:** Click "Manual Entry". An empty form appears.
2. **Input:** Type the data manually. Click "Capture Visitor Photo" to snap a live photo.
3. **Save:** The frontend sends the data + photo + dynamic IDs to the backend. The backend uploads the live photo to Google Drive, checks/sets sheet headers, and appends the manual data + Drive link to the Google Sheet.

### Path 3: Card with Information, but NO Photo
1. **Capture:** Snap a photo of the card.
2. **Processing:** The API sends the image to Gemini. Gemini extracts the JSON data and returns `face_detected: false`. (No Drive upload happens yet).
3. **Preview & Alert:** The frontend auto-fills the form using the typewriter effect. Because `face_detected` is false, it displays an alert: *"No photo detected on card. Please snap visitor face."* alongside a camera trigger.
4. **Save:** After snapping the live photo and reviewing the text, clicking "Save" sends all payloads to the backend. The API uploads the photo to the configured Drive folder and appends the data + link to the configured Sheet.

# Strict Error Handling & Null Safety
1. **Missing Data Rules:** AI extraction MUST NEVER crash if fields are missing. Instruct Gemini: "If a field (e.g., Gender, Age, Address) is missing from the card, set its JSON value to 'N/A' or null."
2. **Backend Safety:** When mapping the JSON data to the `values` array for the Google Sheets API append request, ensure variables map safely (e.g., `data.gender || "N/A"`) so the length of the array matches the headers perfectly.
3. **Stateless Constraints:** The Next.js API routes must remain stateless, serving solely as a bridge to Gemini, Drive, and Sheets.
